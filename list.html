처음 쓰시나요? 설정 방법 (API 키 · 스팀 ID)
  1. IsThereAnyDeal 앱 페이지에서 로그인 (Steam 계정으로 로그인 가능)
  2. Register App → 앱 이름 아무거나 입력 → Submit
  3. 오른쪽 API Keys 칸의 키를 복사 (OAuth의 Client ID·Secret 아님)
  4. 스팀 ID 17자리: 스팀 프로필 주소가 /profiles/7656…이면 그 숫자. /id/이름 형태면 steamid.io에서 steamID64 확인
  5. 스팀 프로필 공개 설정에서 게임 세부 정보를 공개로 (찜목록이 여기에 포함)
